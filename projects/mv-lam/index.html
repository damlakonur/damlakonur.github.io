MV-LAM: Multi-View Fusion for 3D-Complete Head Avatars

Guided research extending the LAM (Large Avatar Model) framework to support two-view input using the CAFCA dataset for more complete and consistent 3D head avatar reconstruction.

Key contributions:

  • Finetuned LAM from single-view to multi-view fusion with num_source_views: 2
  • Introduced a fusion MLP to combine features from two reference images
  • Integrated the CAFCA dataset for training and inference
  • Achieved improved 3D completeness and 3D consistency compared to single-view reconstruction

Built with Python and PyTorch, building on the LAM architecture.
